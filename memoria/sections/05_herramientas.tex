\section{Herramientas y Entorno de Desarrollo}

El desarrollo del proyecto fué realizado en un entorno de Python con Conda y Cuda para Pytorch. Mediante iteraciones utilizando jupyter notebooks, y controlador de versiones Github en este enlace: \url{https://github.com/Ruipi/tfg}.

Además de eso, contamos con un ordenador con una GPU NVIDIA GeForce RTX 5060, que nos permite entrenar el modelo de Transformers de forma eficiente y rápida.
